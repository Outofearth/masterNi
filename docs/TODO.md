### 已完成的「关键宫位对比表」

合婚页在双方都起盘后显示，纯客观数据并排对比：

| 项目 | 说明 |
|---|---|
| 对比宫位 | 命宫 / 夫妻宫 / 福德宫 / 财帛宫 / 官禄宫 |
| 展示内容 | 双方主星 + 双方四化（禄权科忌） |
| 共鸣提示 | 同宫位出现相同主星时标注「共鸣 · 星名」 |
| 空宫处理 | 显示「空宫（借对宫）」 |

### 评分为什么没做

`lib/ziwei/heming-knowledge.ts` 里有 `HEMING_SCORE_CRITERIA`：

```
五星：双方夫妻宫互映天作之合，四化相互补益，大限同走旺运，福德宫双吉
四星：一方夫妻宫对应对方命宫，四化以禄科为主，感情基础扎实
三星：命格相配但各有棱角，需磨合，长期来看稳定
二星：夫妻宫各有煞星，化忌有冲，感情起伏大，需双方主动经营
一星：凶星汇聚夫妻宫，或廉贞三凶组合，生离死别风险高
```

**问题**：这是**定性文字描述**，不是可计算规则。

| 缺口 | 说明 |
|---|---|
| 无权重定义 | 「夫妻宫互映」具体怎么判？命宫对应算几分？ |
| 无扣分项阈值 | 「煞星」指哪些？化忌冲到什么程度降一星？ |
| 无边界条件 | 同星共鸣是加分还是减分？空宫怎么算？ |
| 无验证基准 | 拿什么样本校准分档合理性？ |

### 启动条件

1. 用户（或命理专业方）定义可计算的评分规则：维度 / 权重 / 阈值 / 边界
2. 提供若干已知「好/坏」合婚样本做校准
3. 明确分数是否对外展示（展示分数涉及用户心理影响，需谨慎）

### 风险点

- 自行设计评分 = **AI 编造命理规则**，与项目「不编造」原则冲突
- 合婚分数对用户有实际心理影响，误判成本高于知识库论断
